
# NEXCART

### Discover Products. Compare Prices. Shop Smarter.

NEXCART is a modern e-commerce and price comparison platform designed to help users discover products, explore online stores, and find better shopping deals.

## Overview

NEXCART brings products, stores, and special offers together in one platform with a clean interface and a user-friendly shopping experience.

## Features

- **Product Discovery** — Browse and explore available products.
- **Product Comparison** — Compare products and make better shopping decisions.
- **Store Directory** — Discover different online stores.
- **Special Offers** — Explore available deals and discounts.
- **Product Details** — View detailed product information.
- **Admin Dashboard** — Manage products, stores, categories, and offers.
- **Responsive Design** — Optimized for different screen sizes.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/AmirRahimiyi/NEXCART.git
```

2. Move the project into your XAMPP `htdocs` directory.

3. Start Apache and MySQL using XAMPP.

4. Create a MySQL database for NEXCART.

5. Configure your database connection in:

```text
config/database.php
```

6. Import your database structure and required data.

7. Open the project in your browser:

```text
http://localhost/nexcart/
```

## Database

NEXCART uses MySQL for storing and managing application data.

Make sure your database is configured correctly before running the application.
